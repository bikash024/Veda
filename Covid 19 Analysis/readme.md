# Day 3 - COVID-19 Global Impact Dashboard

## Objective
Analyze global COVID-19 trends across countries using cases, deaths, vaccination coverage, and population-normalized metrics.

## Work Completed
- Combined COVID-19 cases, deaths, and vaccination datasets
- Converted wide-format datasets into long format
- Cleaned and merged data using country and date
- Removed global and regional aggregate rows for country-level analysis
- Analyzed weekly COVID-19 case and death trends
- Compared countries using cases and deaths per million
- Analyzed vaccination rollout across major countries
- Studied the relationship between vaccination coverage and mortality
- Created a Power BI dashboard with KPIs, slicers, trend charts, and country comparisons

## Key Findings
- The United States recorded the highest raw weekly case peak among the selected countries.
- South Korea had the highest peak weekly cases per million among major countries.
- COVID-19 waves peaked at different periods across countries.
- Population-normalized metrics provide a fairer comparison than raw case or death totals.
- Vaccination coverage and mortality showed a weak negative correlation of approximately -0.27 in the selected 2022 country sample.
